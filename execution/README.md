## 执行阶段的关键问题

1. **订单类型选择**：限价单 vs 市价单 vs 止损单
2. **滑点控制**：大额订单如何减少市场冲击
3. **系统稳定性**：网络中断、API 异常如何处理
4. **实时监控**：策略运行状态的跟踪与报警

---

## 模拟交易的意义

在投入真金白银之前，模拟交易可以：
- 验证策略在实时数据下的逻辑正确性
- 熟悉交易软件和 API 操作
- 培养对策略波动的耐受力
- 记录真实的交易心理和决策过程
