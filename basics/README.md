## 学习建议

1. **不要跳过基础**：很多策略代码看不懂，往往是因为 Pandas 或统计概念不熟。
2. **边学边写**：每个知识点都要写代码验证，光看不动手等于白学。
3. **建立联系**：学统计时想想金融市场的例子，学金融时想想怎么用代码实现。
