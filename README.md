## 🏷️ 文件标签说明

我在文件名中会使用以下标签，方便你快速识别内容类型：

| 标签 | 含义 | 示例 |
|------|------|------|
| `[note]` | 学习笔记/总结 | `pandas-basics-[note].md` |
| `[code]` | 可运行代码 | `dual-ma-strategy-[code].py` |
| `[backtest]` | 回测相关 | `momentum-backtrader-[backtest].py` |
| `[data]` | 数据处理 | `akshare-download-[data].py` |
| `[project]` | 完整项目 | `statistical-arbitrage-[project]/` |
