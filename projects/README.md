## 项目标准结构

每个项目应是一个独立的文件夹，结构如下：

```
project-name-[project]/
├── README.md                 # 项目说明文档
├── requirements.txt          # 依赖包清单
├── data/                     # 项目数据
├── src/                      # 源代码
│   ├── data_loader.py
│   ├── strategy.py
│   ├── backtest.py
│   └── report.py
├── notebooks/                # 探索性分析
├── results/                  # 回测结果、图表
└── config.yaml               # 配置文件
```

---

## 项目文档（README.md）应包含

1. **项目背景**：为什么要做这个项目？
2. **策略逻辑**：核心假设和交易规则
3. **数据来源**：用了什么数据，从哪获取
4. **回测结果**：关键指标和图表
5. **总结反思**：做得好的地方、不足、下一步计划
