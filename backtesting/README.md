## 回测中的常见陷阱

1. **前瞻性偏差（Look-ahead Bias）**：用未来的信息做当下的决策
2. **过拟合（Overfitting）**：策略在历史数据上过度优化
3. **幸存者偏差（Survivorship Bias）**：只使用存活至今的股票数据
4. **忽略交易成本**：手续费、滑点、冲击成本会显著侵蚀收益
5. **数据挖掘偏差（Data Mining Bias）**：随机数据中也能找到"显著"模式

## 常用评估指标

| 指标 | 说明 |
|------|------|
| 年化收益率 | 策略一年的平均收益率 |
| 最大回撤 | 净值从高点到低点的最大跌幅 |
| 夏普比率 | 单位风险带来的超额收益 |
| 卡玛比率 | 年化收益 / 最大回撤 |
| 胜率 | 盈利交易次数 / 总交易次数 |
| 盈亏比 | 平均盈利 / 平均亏损 |
