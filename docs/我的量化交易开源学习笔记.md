# 🗺️ 量化交易学习路线图

> 这是一个动态更新的学习规划。完成的项目会打 ✅，进行中的打 🔄，未开始的打 ⬜。

---

## Phase 1: 筑基期 🧱
**目标**：掌握量化交易所需的编程、数学和金融基础

### 1.1 Python 量化编程
- ⬜ NumPy 数组操作与向量化计算
- ⬜ Pandas 数据处理（索引、分组、时间序列）
- ⬜ 数据可视化（Matplotlib / Plotly）
- ⬜ 面向对象编程与代码组织

### 1.2 统计学基础
- ⬜ 描述统计与概率分布
- ⬜ 假设检验与置信区间
- ⬜ 线性回归与相关性分析
- ⬜ 时间序列基础（平稳性、自相关）

### 1.3 金融市场知识
- ⬜ 股票市场基础（A股/港股/美股）
- ⬜ 订单类型与交易成本
- ⬜ 期货与期权入门
- ⬜ 市场微观结构基础

---

## Phase 2: 兵器谱 ⚔️
**目标**：掌握数据获取、回测和可视化的工具链

### 2.1 数据获取
- ⬜ 使用 `yfinance` 获取美股数据
- ⬜ 使用 `akshare` 获取 A股数据
- ⬜ 使用 `tushare` 获取财务数据
- ⬜ 数据清洗、存储与管理

### 2.2 回测框架
- ⬜ Backtrader 基础（Cerebro、DataFeed、Strategy）
- ⬜ VectorBT 快速向量化回测
- ⬜ 回测中的过拟合与前瞻性偏差
- ⬜ 绩效指标计算（Sharpe、Max Drawdown、Calmar）

### 2.3 可视化
- ⬜ K线图与技术指标可视化
- ⬜ 回测结果图表展示
- ⬜ 热力图与相关性矩阵

---

## Phase 3: 招式库 📜
**目标**：学习并复现经典量化策略

### 3.1 动量策略（Momentum）
- ⬜ 双均线策略（Dual Moving Average）
- ⬜ 通道突破策略（Donchian Channel）
- ⬜ 相对强弱策略（RSI / MACD）

### 3.2 均值回归（Mean Reversion）
- ⬜ Bollinger Bands 策略
- ⬜ RSI 超买超卖策略
- ⬜ 短期反转策略

### 3.3 因子投资（Factor Investing）
- ⬜ Fama-French 三因子模型
- ⬜ 价值因子与动量因子
- ⬜ 多因子选股模型

### 3.4 配对交易（Pairs Trading）
- ⬜ 协整检验与配对选择
- ⬜ 均值回归型配对交易策略
- ⬜ 波动率调整仓位

---

## Phase 4: 心法篇 🛡️
**目标**：理解风险管理和组合优化的核心思想

### 4.1 仓位管理
- ⬜ 固定金额 vs 固定比例
- ⬜ 凯利公式（Kelly Criterion）
- ⬜ 波动率目标仓位管理

### 4.2 组合优化
- ⬜ 马科维茨均值-方差优化
- ⬜ 风险平价（Risk Parity）
- ⬜ Black-Litterman 模型（进阶）

### 4.3 风险评估
- ⬜ VaR 与 CVaR
- ⬜ 最大回撤分析
- ⼀ 蒙特卡洛模拟

---

## Phase 5: 实战场 🚀
**目标**：从回测走向模拟交易和自动化执行

### 5.1 模拟交易
- ⬜ 搭建纸面交易系统
- ⬜ 记录交易日志与绩效跟踪
- ⬜ 策略运行监控与异常处理

### 5.2 API 对接
- ⬜ 了解券商 API（如富途、Interactive Brokers）
- ⬜ 订单发送与状态查询
- ⬜ 实时数据订阅与处理
