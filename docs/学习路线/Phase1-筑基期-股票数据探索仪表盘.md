# Phase 1：筑基期 — 股票数据探索仪表盘

> **设计日期**：2026-04-25  
> **适用对象**：大一金融工程学生，Python/金融/统计均有入门基础  
> **时间投入**：每天1小时，共3-4周  
> **学习目标**：独立完成"获取数据 → 清洗处理 → 计算指标 → 统计洞察 → 可视化展示"的完整流程

---

## 🎯 牵引项目

**项目名称**：📊 股票数据探索仪表盘 (Stock Data Exploration Dashboard)  
**最终交付物**：一个可运行的 Jupyter Notebook，输入任意A股股票代码，一键输出包含数据概览、统计指标、可视化图表的完整分析报告。

---

## 🗓️ 周计划拆解

### 第1周：环境搭建与数据获取

**核心任务**：搭建项目环境，学会用 API 获取真实股票数据。

**弹性诊断**：如果你已经会用 `requests`/爬虫，这部分1天就能搞定；如果完全没用过，需要3天。

**学习内容**：
- 配置 Python 虚拟环境，安装 `pandas`, `numpy`, `akshare`, `matplotlib`
- 使用 `akshare` 获取A股历史行情数据（日线）
- 理解数据结构：开盘价、收盘价、最高价、最低价、成交量、成交额

**项目里程碑**：✅ 成功下载任意一只股票（如 `000001` 平安银行）近3年的日线数据，保存为 CSV。

---

### 第2周：pandas 数据处理实战

**核心任务**：掌握量化场景最常用的数据处理操作。

**弹性诊断**：跳过你已经会的 `DataFrame` 基础操作，重点攻克时间序列特有的方法。

**学习内容**：
- 日期索引与重采样（`resample`）
- 计算日收益率（`pct_change`）和对数收益率
- 计算简单移动平均线（MA5, MA20, MA60）
- 数据清洗：处理停牌日、缺失值、除权除息影响

**项目里程碑**：✅ 在 Notebook 中展示某只股票的收盘价、MA5、MA20 的对比图。

---

### 第3周：统计知识的量化应用

**核心任务**：把大学统计课学到的概念，真正用在金融数据上。

**学习内容**：
- 描述性统计：年化收益率、年化波动率、夏普比率的雏形
- 收益率分布：画直方图，观察"肥尾"现象
- 相关性：计算两只股票收益率的相关系数矩阵
- **论文素养植入**：学习写一段"描述性统计小结"，规范地报告均值、标准差、偏度、峰度

**项目里程碑**：✅ 生成一份某股票的"数据体检报告"（含统计表 + 分布图 + 简要解读）。

---

### 第4周：可视化整合与仪表盘成型

**核心任务**：把前面的工作整合成一个完整的、可展示的分析流程。

**学习内容**：
- `matplotlib` 基础：子图布局、中文显示、颜色搭配
- 绘制多面板图：价格+均线、成交量、收益率分布
- 封装小函数：写一个 `analyze_stock(code, start, end)` 函数，输入代码和日期就能输出完整分析

**项目里程碑**：✅ **股票数据探索仪表盘 v1.0** 完成——输入任意股票代码，一键输出分析报告。

## 💡 给未来论文的铺垫

从 Phase 1 开始，每完成一个项目，请尝试用以下结构写一段 200-300 字的"微型摘要"：

1. **研究对象**：分析了哪只股票/哪些数据？
2. **方法**：用了什么指标和工具？
3. **发现**：数据呈现了什么特征？（如波动率如何、收益率分布是否对称）
4. **结论/局限**：这个分析能说明什么？还有什么不足？

这种训练会让你在 Phase 6 写论文时，自然具备学术表达的习惯。
