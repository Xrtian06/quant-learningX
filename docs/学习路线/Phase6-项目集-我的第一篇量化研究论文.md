# Phase 6：项目集 — 我的第一篇量化研究论文

> **设计日期**：2026-04-25  
> **适用对象**：大二金融工程专业学生，已完成 Phase 1-5  
> **时间投入**：每天2小时，建议在大二上学期（9月-次年1月）集中推进  
> **学习目标**：独立完成一篇格式规范、有实证分析、有学术引用的量化研究论文

---

## 🎯 牵引项目

**项目名称**：🏗️ 我的第一篇量化研究论文 (My First Quantitative Research Paper)  
**最终交付物**：一篇5000-10000字的完整论文，含文献综述、研究方法、实证分析、结论讨论

---

## 🗓️ 阶段拆解（按里程碑推进）

### 阶段1：选题与文献调研（2-3周）

**核心任务**：找到一个好问题——足够具体、有文献支撑、数据可获得。

**推荐选题方向**（适合大二金融工程学生）：

| 方向 | 示例题目 | 数据需求 | 难度 |
|------|----------|----------|------|
| **A. 因子有效性检验** | "低波动率因子在A股市场的有效性研究" | A股历史行情 | ⭐⭐ |
| **B. 策略改进** | "基于RSI的均值回归策略改进：加入成交量确认信号" | A股历史行情 | ⭐⭐ |
| **C. 市场异象** | "A股市场的月度效应：月初效应与月末效应检验" | A股指数/个股数据 | ⭐⭐⭐ |
| **D. 组合优化** | "风险平价策略与传统均值方差模型的对比研究" | 多资产历史数据 | ⭐⭐⭐ |
| **E. 行为金融** | "散户情绪指标与A股市场收益的领先滞后关系" | 行情数据+情绪代理指标 | ⭐⭐⭐⭐ |

**推荐方向 A 或 B**——直接建立在 Phase 3-4 的工作基础上，只需"做得更规范、测得更严谨"。

**论文素养植入**：
- 学会用 **Zotero/EndNote** 管理文献
- 每读一篇论文，用"一页纸笔记法"记录：研究问题、方法、数据、结论、启发
- 撰写 500 字"文献综述"：这个领域已经做了什么？还有什么空白？

**里程碑**：✅ 确定选题 + 完成 5-8 篇核心文献阅读 + 文献综述初稿

---

### 阶段2：研究设计与方法论（2周）

**核心任务**：把"想研究什么"转化为"怎么研究"。

**学习内容**：
- **研究假设**：提出可检验的 H0 和 H1
- **样本选择**：研究区间？剔除ST股票？如何处理停牌？
- **变量定义**：因子/策略信号如何计算？（精确到代码级别）
- **检验方法**：
  - **IC 分析**（Information Coefficient）：因子与下期收益的相关性
  - **分层回测**（Quantile Analysis）：按因子值分组，观察组间收益单调性
  - **IR 比率**（Information Ratio）：IC 的均值/标准差
  - **T 检验**：策略收益是否显著不为零
  - **Newey-West 调整**：处理时间序列的相关性

> 📚 **推荐阅读**：《Quantitative Equity Portfolio Management》（Qian, Sorensen）或《因子投资：方法与实践》

**里程碑**：✅ "研究方法"章节 + 数据获取和清洗代码

---

### 阶段3：实证分析（4-6周）

**核心任务**：跑数据、出结果、做稳健性检验。

**工作内容**：
- 主检验：运行核心分析，记录所有结果
- **稳健性检验**（Robustness Checks）：
  - 换时间段：子样本检验（牛市/熊市/震荡市）
  - 换参数：改变回看周期、分组数量
  - 换样本：剔除小市值股票、剔除金融行业
  - 加入控制变量：市值、行业、动量等
- 结果可视化：专业图表（热力图、分组收益柱状图、累计收益曲线）

**论文素养植入**：
- 结果表格规范：列名清晰、保留2-4位小数、标注显著性（***, **, *）
- 每张图配"图注说明"：展示了什么？关键结论是什么？

**里程碑**：✅ 主检验完成 + 至少 3 种稳健性检验 + 完整图表和表格

---

### 阶段4：论文写作（3-4周）

**核心任务**：把研究变成一篇可读、规范的论文。

**标准结构**：
1. **摘要**（200-300字）
2. **引言**（800-1000字）
3. **文献综述**（1000-1500字）
4. **研究方法**（1000-1500字）
5. **实证结果**（1500-2000字）
6. **结论与讨论**（500-800字）
7. **参考文献**

**写作建议**：
- 不要从头写到尾！先写**研究方法**，再写**实证结果**，最后写**引言**
- 每段开头用"主题句"概括全段内容
- 用 LaTeX 或 Word + Zotero 管理格式和引用

**里程碑**：✅ 完整初稿

---

### 阶段5：修改与打磨（2-3周）

**核心任务**：让论文从"能看"变成"好看"。

**检查清单**：
- [ ] 每句话都有明确贡献，没有废话
- [ ] 图表清晰、编号规范、图注完整
- [ ] 引用格式统一（GB/T 7714 或 APA）
- [ ] 数学公式编号规范
- [ ] 通读一遍，检查逻辑断层和跳跃
- [ ] 请同学/老师提意见，至少修改两轮

**里程碑**：✅ 终稿定稿 + 准备答辩/投稿

## ⏰ 每天2小时分配建议（论文阶段）

写论文需要"沉浸"和"深度思考"，建议采用 **番茄工作法**：

| 时间块 | 内容 |
|--------|------|
| **50分钟** | 深度工作（读文献/写代码/写作） |
| **10分钟** | 休息 |
| **50分钟** | 深度工作 |
| **10分钟** | 休息 |

每周至少留一天"不写论文"，让大脑休息。
