## 一、这个仓库是干什么的？

这是一个**量化交易学习仓库**。我把每一次学习的内容、代码、心得都开源在这里。

它不是一份 polished 的教程，而是一个**真实的、正在成长的学习记录**。你可以看到：
- 我从零开始学了什么
- 每个知识点的代码实现
- 踩过的坑和总结
- 逐渐复杂的策略项目

## 二、目录结构详解

### 📘 `docs/` - 文档区
这是整个仓库的"说明书"，你现在看的就是其中一篇。

| 文件 | 作用 |
|------|------|
| `how-to-read-this-repo.md` | 仓库使用指南（就是这篇） |
| `roadmap.md` | 我规划的学习路线图 |
| `glossary.md` | 量化术语表，遇到不懂的词来这里查 |

### 🧱 `basics/` - 基础知识
**还没碰策略之前，先打基础。**

包含三个方向：
- **`python-for-quant/`**：Python 量化必备技能（NumPy, Pandas, 数据处理）
- **`statistics/`**：统计学基础（描述统计、假设检验、时间序列）
- **`financial-markets/`**：金融市场知识（股票、期货、期权基础）

### 📊 `data/` - 数据获取与处理
**数据是量化的燃料。**

这里放各种获取市场数据的代码：
- `yfinance/`：美股数据
- `akshare/`：A股免费数据
- `tushare/`：A股专业数据（需要积分/token）

每个子文件夹里会有：数据下载脚本、清洗代码、存储示例。

### 🔁 `backtesting/` - 回测框架学习
**策略写完要验证，回测是必经之路。**

包含主流回测框架的学习笔记和代码：
- `backtrader/`：事件驱动型回测框架
- `vectorbt/`：向量化回测，速度快
- `zipline/`：Quantopian 开源框架

### ⚔️ `strategies/` - 策略学习
**这是重头戏，按策略类型分类。**

| 文件夹 | 策略类型 | 说明 |
|--------|----------|------|
| `momentum/` | 动量策略 | 追涨杀跌，趋势跟踪 |
| `mean-reversion/` | 均值回归 | 跌多了买，涨多了卖 |
| `factor-investing/` | 因子投资 | 多因子选股/选基 |
| `pairs-trading/` | 配对交易 | 统计套利，相关性交易 |

每个策略文件夹里通常包含：
- 策略原理说明（Markdown）
- 复现代码（Python）
- 回测结果与分析

### 🛡️ `risk-management/` - 风险管理
**活得久比赚得快更重要。**

- `position-sizing/`：仓位管理（凯利公式、固定比例、波动率目标）
- `portfolio-construction/`：组合优化（马科维茨、风险平价、Black-Litterman）

### 🚀 `execution/` - 交易执行
**从回测到实盘，执行是最后一公里。**

- `paper-trading/`：模拟交易记录与代码
- `api-integration/`：券商/交易所 API 对接（如富途、IB、聚宽）

### 📓 `notebooks/` - Jupyter 学习笔记
**零散但重要的探索过程。**

这里放一些不太好分类的 Jupyter Notebook：
- 数据分析探索
- 新包试用
- 临时想法验证

### 🏗️ `projects/` - 完整项目
**把前面学的东西整合起来，做成完整项目。**

每个项目是一个独立文件夹，包含：
- 项目背景与目标
- 完整代码
- 回测/实盘结果
- 总结反思

## 三、文件命名规则

为了快速识别文件内容，我采用统一的命名规范：

```
<主题>-<类型标签>.<扩展名>
```

### 类型标签

| 标签 | 含义 | 示例 |
|------|------|------|
| `[note]` | 学习笔记、知识点总结 | `pandas-groupby-[note].md` |
| `[code]` | 可独立运行的代码 | `bollinger-bands-[code].py` |
| `[backtest]` | 回测代码/结果 | `dual-ma-backtrader-[backtest].py` |
| `[data]` | 数据处理脚本 | `clean-stock-data-[data].py` |
| `[viz]` | 可视化相关 | `candlestick-matplotlib-[viz].py` |
| `[project]` | 完整项目（用于文件夹） | `factor-momentum-[project]/` |

### 示例

```
strategies/
├── momentum/
│   ├── momentum-principle-[note].md
│   ├── dual-ma-strategy-[code].py
│   └── dual-ma-backtrader-[backtest].py
```

## 四、如何跟着我的路径学习？

### 推荐学习顺序

```
1. 读 docs/roadmap.md → 了解整体规划
2. 从 basics/ 开始 → 补齐基础
3. 学 data/ → 学会获取和处理数据
4. 学 backtesting/ → 掌握至少一个回测框架
5. 进入 strategies/ → 逐个复现经典策略
6. 学习 risk-management/ → 给策略加上风控
7. 尝试 execution/ → 走向模拟/实盘
8. 做 projects/ → 整合所学，产出作品
```

### 每个文件夹里的 README

每个一级目录下都有 `README.md`，记录了：
- 这个模块的学习目标
- 已完成的子项清单
- 推荐阅读的资源
