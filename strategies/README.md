# ⚔️ 策略学习

> 经典策略是理解量化交易的最好教材。先复现，再优化，最后创新。

---

## 目录说明

| 子目录 | 策略类型 | 核心思想 | 状态 |
|--------|----------|----------|------|
| `momentum/` | 动量策略 | 追涨杀跌，趋势跟踪 | ⬜ |
| `mean-reversion/` | 均值回归 | 跌多了买，涨多了卖 | ⬜ |
| `factor-investing/` | 因子投资 | 用因子解释和预测收益 | ⬜ |
| `pairs-trading/` | 配对交易 | 统计套利，协整关系 | ⬜ |

---

## 策略文件标准结构

每个策略文件夹建议包含：

```
strategy-name/
├── <strategy>-principle-[note].md     # 策略原理说明
├── <strategy>-[code].py               # 核心逻辑代码
├── <strategy>-[backtest].py           # 回测代码
└── results/                           # 回测结果（图表、数据）
```

---

## 学习每一个策略时要思考的问题

1. **假设是什么？** 这个策略基于什么样的市场假设？
2. **什么时候有效？** 在什么样的市场环境下表现好？
3. **什么时候失效？** 什么情况下会亏钱？
4. **风险在哪？** 最大的风险敞口是什么？
5. **如何改进？** 有没有可以优化的方向？
